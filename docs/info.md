## How it works

Integración de memoria SRAM 32x32 generada con OpenRAM junto al procesador FemtoRV32 (`tt_um_femto`).

## How to test

Ejecutar la simulación funcional con cocotb desde `tinytapeout/` mediante `make cocotb_openram`.

## External hardware

Memoria SPI Flash externa para almacenamiento de firmware.
